# Sands websites

Multi-product workspace for Sands web redesign and rebuild work in Aotearoa New Zealand.

This is **not** a single app. Each site is a product folder. Anything reusable across sites lives in `shared/`.

| **Auckland Central** | [`products/auckland/`](products/auckland/) | Regional prototype and reference (`sandsauckland.org.nz`). Planning + draft build exist. |
