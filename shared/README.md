# Shared

Product-agnostic material used (or intended for use) by more than one site in this workspace.

## What belongs here

Only things that are **not tied to a single product**:

- Design tokens, type, and tone that both sites should inherit
- Org-wide principles (e.g. continuity, DRAFT review) once written as portable docs
- Brand assets that are not Auckland- or national-specific

## What does not belong here

Default to the product folder if unsure:

- Page briefs, IA, or content schedules
- HTML builds
- Captures of a live site (`V0-*`)
- Region- or product-specific copy, contacts, or events
- Anything still being decided for one product only

## Current contents

Empty except this README. Populate by extract/copy from a product only when something is clearly reusable.
